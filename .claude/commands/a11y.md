다음 파일의 접근성을 검토해줘: $ARGUMENTS

## 확인 항목

### 1. 키보드 네비게이션
- Tab 순서가 논리적인지
- Enter/Space로 활성화 가능한지
- Escape로 모달/팝업 닫기 가능한지
- 포커스 트랩 적절한지 (모달 내부)

### 2. ARIA 속성
- role 속성 적절성
- aria-label, aria-labelledby 사용
- aria-expanded, aria-pressed 상태 반영
- aria-live 영역 (동적 콘텐츠)

### 3. 시각적 접근성
- 색상 대비 (oklch 기준, 4.5:1 이상)
- 포커스 표시 가시성 (:focus-visible)
- 텍스트 크기 및 줌 지원

### 4. 스크린 리더
- 의미 있는 대체 텍스트 (alt, aria-label)
- 숨김 요소 처리 (aria-hidden)
- 읽기 순서 논리성

## 출력 형식
- 발견된 문제점 목록
- 각 문제의 심각도 (높음/중간/낮음)
- 수정 코드 예시
