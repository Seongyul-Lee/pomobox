$ARGUMENTS 파일의 다국어(i18n) 구현을 검토한다.

## 기본 설정
- 기본 경로: `/en`
- 지원 언어: 확인 필요

## 검토 항목

### 1. 하드코딩 텍스트
- UI에 직접 작성된 문자열 검출
- 버튼, 라벨, 메시지, 에러 텍스트
- placeholder, title, alt 속성

### 2. 번역 키
- 키 네이밍 일관성 (snake_case / camelCase)
- 계층 구조 적절성
- 누락된 번역 키 확인

### 3. 동적 콘텐츠
- 변수 삽입 처리 ({name}, {{count}})
- 복수형 처리 (singular/plural)
- 성별 처리 (필요시)

### 4. 포맷팅
- 날짜 포맷 (로케일별)
- 숫자 포맷 (천 단위 구분자)
- 통화 포맷 (필요시)

### 5. RTL 지원
- 아랍어/히브리어 대응 여부
- direction 속성 동적 설정
- 레이아웃 미러링

### 6. 파일 구조
```
locales/
├── en/
│   └── common.json
├── ko/
│   └── common.json
└── ...
```

## 출력 형식
- 하드코딩된 텍스트 목록 (파일:라인)
- 누락된 번역 키
- 수정 코드 예시
