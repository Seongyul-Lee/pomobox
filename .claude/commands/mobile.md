$ARGUMENTS 컴포넌트의 모바일 반응형을 검토한다.

## 검토 항목

### 1. Tailwind 브레이크포인트
- `sm:` (640px) - 소형 태블릿
- `md:` (768px) - 태블릿
- `lg:` (1024px) - 데스크톱
- Mobile First 원칙 준수 (기본 = 모바일)

### 2. 터치 인터랙션
- 터치 타겟 크기 (최소 44x44px)
- hover 대신 active 상태 처리
- 스와이프 제스처 지원 여부

### 3. 레이아웃
- 가로 스크롤 발생 여부
- 뷰포트 오버플로우 확인
- 플렉스/그리드 반응형 설정
- 고정 너비(px) 대신 상대 단위(%, vw, rem) 사용

### 4. 타이포그래피
- 텍스트 크기 가독성 (최소 16px)
- 줄 길이 적절성 (45-75자)
- 텍스트 줄바꿈 처리

### 5. 미디어
- 이미지 반응형 (max-width: 100%)
- 비디오/iframe 비율 유지
- 로딩 성능 (lazy loading)

## 테스트 해상도
- 360px (소형 모바일)
- 390px (iPhone 14)
- 768px (iPad)
- 1024px (iPad Pro / 소형 데스크톱)

## 출력 형식
- 문제점 목록 (해상도별)
- 수정 코드 예시
- 우선순위 (높음/중간/낮음)
