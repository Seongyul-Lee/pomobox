통계 관련 변경사항을 검토한다.

## 필수 확인 파일
- @lib/storage/ (IndexedDB 저장소)
- @app/stats/ (통계 페이지)
- @components/dashboard-right.tsx (캘린더, Check-in)

## 검토 항목

### 1. 기록 정책
- 세션 완료 시에만 기록되는지 확인
- 중간 취소/리셋 시 기록되지 않는지
- 중복 기록 방지 로직

### 2. 데이터 정합성
- IndexedDB 스키마 일관성
- 필수 필드 누락 여부
- 데이터 타입 검증

### 3. 시간 처리
- UTC vs Local 시간대 일관성
- 날짜 경계 처리 (자정 기준)
- 타임존 변경 시 동작

### 4. Rolling 4-Week 로직
- 주간 집계 정확성
- 이전 주 데이터 포함 여부
- 경계 조건 (월초/월말)

### 5. 집계 함수
- 일일/주간/월간 합계
- 평균 계산 정확성
- 빈 데이터 처리 (0 vs null)

### 6. 성능
- 대용량 데이터 쿼리 최적화
- 인덱스 활용 여부
- 불필요한 재계산 방지

## 출력 형식
- 발견된 문제점
- 데이터 흐름 다이어그램 (텍스트)
- 수정 권장사항
