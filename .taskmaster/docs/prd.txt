# pomobox 개요

- 제품: pomobox (Pomodoro timer + 통계/설정)
- 목표: 정확한 타이머 상태/통계 정책의 일관성 유지
- 원칙: 최소 변경 + 근거 기반 + 롤백 가능성 유지 + 기능 구현 시 추후 연계되는 기능들을 생각하며 작업 + 대부분의 작업은 '/en'가 기준
- 제약: 이유없이 하드코딩 금지

---

## 기술 스택

- Frontend: Next.js 15 (App Router), React 19, TypeScript
- Styling: Tailwind CSS, oklch 색상 표현
- State: Zustand (클라이언트), React Query (서버 상태)
- Backend: Supabase (Auth, Database, Realtime)
- Storage: IndexedDB (오프라인), Supabase PostgreSQL (온라인)

---

## UI/UX 기준

- 데스크탑 개발 환경 해상도: QHD(2560x1440)
- 다른 데스크탑 해상도 대응: 미디어 쿼리로 "조정"
- 모바일: Mobile First (Tailwind 기본 = 모바일, md: = 데스크탑)
- color 표현 방식: oklch

## [2차 기능 구현 목표]

### 좌측 사이드바 (대시보드 대체)
- 상단: pomobox.app 아이콘
- 중단: Timer, Task, 통계 아이콘, Settings
- 하단: "Sign in" 버튼

### Task 기능
- 좌측에서 우측으로 슬라이드 탭
- 텍스트로 작업 작성/편집/삭제
- 최대 30개 작업 (스크롤 바)
- 비로그인: localStorage 저장
- 로그인: Supabase 저장

### 통계 페이지
- Weekly Stats: Area/Line/Bar chart 옵션
- This Week vs Last Week: 전주 대비 비교
- Rolling 4-Week: 최근 4주 데이터 (오늘 기준 역산)
  - 예: 12월 3일 → [11월 2주 | 11월 3주 | 11월 4주 | 12월 1주]
  - 데이터 없는 주: 연한 회색 빈 막대

## [3차 기능 완성 목표]

### 로그인 유도
- 비로그인 사용자 첫 세션 완료 시 팝업/대시보드
- 예시: "첫 세션 완료! 기록을 남기고 싶다면 로그인하세요."

### 고급 통계
- 시간대별 집중도 (Focus Distribution by Time): 24시간 라인 차트/히트맵
- 카테고리/태그별 비중 (Focus Categories): Donut/Pie Chart
- 집중 스트릭 (Focus Streak): "현재 5일 연속!", "최대: 15일"
- 집중 vs 휴식 비율 (Focus to Break Ratio): 최근 6개월

## 백엔드 아키텍처 (Supabase)

### 인증 (Supabase Auth)

| 방식 | 설명 |
|------|------|
| Email/Password | 기본 인증 |
| Google OAuth | 소셜 로그인 |
| Email 인증 | Magic Link 또는 OTP |

### 데이터베이스 스키마 (PostgreSQL)

```sql
-- 사용자 (Supabase Auth 연동)
users (
  id UUID PRIMARY KEY REFERENCES auth.users,
  email TEXT,
  display_name TEXT,
  timezone TEXT DEFAULT 'Asia/Seoul',
  created_at TIMESTAMPTZ DEFAULT now()
)

-- Focus 세션 기록
focus_sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  duration_minutes INTEGER NOT NULL,
  completed_at TIMESTAMPTZ DEFAULT now(),
  category TEXT,  -- 3차: 카테고리/태그
  INDEX idx_user_completed (user_id, completed_at)
)

-- 일별 집계 테이블 (성능 최적화)
daily_stats (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  date DATE NOT NULL,
  total_sessions INTEGER DEFAULT 0,
  total_minutes INTEGER DEFAULT 0,
  streak_count INTEGER DEFAULT 0,
  UNIQUE(user_id, date)
)

-- Task 목록 (2차)
tasks (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  content TEXT NOT NULL,
  completed BOOLEAN DEFAULT false,
  order_index INTEGER,
  created_at TIMESTAMPTZ DEFAULT now()
)

-- Check-in 출석 (1차)
check_ins (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  date DATE NOT NULL,
  UNIQUE(user_id, date)
)

-- 사용자 설정
user_settings (
  user_id UUID PRIMARY KEY REFERENCES users(id),
  focus_duration INTEGER DEFAULT 25,
  break_duration INTEGER DEFAULT 5,
  long_break_duration INTEGER DEFAULT 15,
  daily_goal INTEGER DEFAULT 8,
  sound_enabled BOOLEAN DEFAULT true,
  sound_type TEXT DEFAULT 'bell',
  volume INTEGER DEFAULT 50,
  language TEXT DEFAULT 'en'
)
```

### Row Level Security (RLS)

```sql
-- 모든 테이블에 RLS 활성화
ALTER TABLE focus_sessions ENABLE ROW LEVEL SECURITY;
ALTER TABLE daily_stats ENABLE ROW LEVEL SECURITY;
ALTER TABLE tasks ENABLE ROW LEVEL SECURITY;

-- 정책: 본인 데이터만 접근
CREATE POLICY "Users can only access own data"
ON focus_sessions FOR ALL
USING (auth.uid() = user_id);
```

### API 엔드포인트 (Next.js API Routes)

| Method | Endpoint | 설명 |
|--------|----------|------|
| POST | `/api/sessions` | 세션 완료 기록 |
| GET | `/api/stats/daily` | 일별 통계 조회 |
| GET | `/api/stats/weekly` | 주간 통계 조회 |
| GET | `/api/stats/monthly` | 월간 통계 조회 |

| GET/PUT | `/api/settings` | 사용자 설정 |

### 데이터 동기화 정책

| 상태 | 저장소 | 동기화 |
|------|--------|--------|
| 비로그인 | IndexedDB/localStorage | 로컬만 |
| 로그인 시 | 로컬 → Supabase | 1회 마이그레이션 |
| 로그인 후 | Supabase | 실시간 (Realtime 또는 polling) |

### 마이그레이션 로직 (로그인 시)

```typescript
// 로그인 성공 후 실행
async function migrateLocalData(userId: string) {
  const localSessions = await getLocalSessions();  // IndexedDB

  if (localSessions.length > 0) {
    await supabase.from('focus_sessions').insert(
      localSessions.map(s => ({ ...s, user_id: userId }))
    );
    await clearLocalSessions();  // 마이그레이션 후 로컬 삭제
  }
}
```

### 성능 최적화

- **집계 테이블**: daily_stats로 일별 통계 미리 계산
- **인덱스**: user_id + completed_at 복합 인덱스
- **캐싱**: React Query staleTime 설정 (통계 5분, 실시간 데이터 30초)
- **페이지네이션**: 히스토리 조회 시 cursor 기반 페이징
